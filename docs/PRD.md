# PRD: 티끌 (Tikkeul)

> 2026 금융 AI Challenge 출품작. 슬로건 **"영끌 아닌 티끌"** — 취업 준비하며 쓸 돈, 몰라서 내지 않게.
> 상세 기획·명세 원문은 `docs/reference/` (1차생각, 기능명세서, STATUS 등).

## 목표
취준생의 프로필(설문 + 마이데이터)과 취업 준비 일정을 전국 청년·취준 정책(약 4,400건)과 대조해, 받을 수 있는 혜택을 AI가 능동적으로 찾아 절약액까지 계산한다. "지원금 검색"이 아니라 "취업 준비 비용 절감 Agent".

## 사용자
- 졸업(예정) 후 미취업 청년, 이직·재취업 준비자 (만 19~34세 중심)
- 시험·면접·이사·퇴사 같은 일정이 있고, 정책이 있어도 찾아 신청하지 못하는 사람
- 데모: 페르소나 3종 — 김민지(시험 시즌·서울 중랑구) / 박준호(면접 러시·경기 수원) / 이서연(퇴사 후 전환·구직급여 수급)

## 핵심 기능
1. **프로필 시작** — 페르소나 선택(마이데이터 mock 자동 분석) 또는 직접 입력(설문 11 + 금융 6). 마이데이터 → 월소득·월세·수급 수당(종료 추정)·취준 지출을 규칙 기반으로 도출
2. **머니캘린더 + 일정 → AI 정책 매칭** — 일정 등록 시 의미 추출 → 지역·키워드 SQL 후보 → LLM이 최대 3건 선별(이유·혜택·신청 링크)
3. **상태 변화 감지** — 이사 일정 → 새로 열리는/사라지는 혜택 델타 리포트 → 적용 시 `profile_changes`로 거주지 전환
4. **정책 상세 + 자격 판정** — 규칙엔진(구조화 조건) 우선, 조건 없는 정책은 LLM 판정. "가능성 높음 / 추가 확인 필요 / 요건 미충족" + 근거·증빙
5. **마이티끌 + 절약 위젯** — 정책 담기, 예상 절약액·건수 합산
6. **AI 채팅** — LangGraph 오케스트레이터 → 정책 검색·조회·비교 / 프로필 수정 에이전트
7. **채용공고** — 공고 수집·키워드/NCS 매칭·필터(고용형태·경력·기관형태)
8. **취업 후 시뮬레이션** — 기업구분·연봉·목표 → 세후 실수령, 한 달 흐름, 3 시나리오 도달 시점, 취업 후 열리는 제도, AI 해설
9. **신규 정책 발견 크론** — 매일 국가 API 증분 재수집, 웹 발견물은 격리 큐

## MVP 제외 사항
- 회원가입·로그인, 실명·연락처·계좌번호 수집 (닉네임 기반 세션만)
- 마이데이터 실연동 (표준 규격 mock만)
- 정책 신청 대행·자동 제출
- 벡터 검색(pgvector) — v2
- 시뮬레이션 결과 저장, 부양가족·특별공제까지 반영한 정밀 세금 계산
