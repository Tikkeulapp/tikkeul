### 기존 서비스의 실제 빈틈

예를 들어 청년몽땅정보통은 현재 서울시 정책만 해도 일자리뿐 아니라 **주거, 금융복지, 교육문화 등 청년 전반**을 다룹니다. AI 맞춤 추천도 제공하지만 기본적인 서비스 단위는 여전히 **‘청년정책 포털’**입니다.

고용24도 마찬가지입니다. 국민취업지원제도, 내일배움카드, 채용, 직업훈련 등을 제공하지만 **취준생 개인의 실제 취업 준비 이벤트를 따라다니면서 경제적 혜택을 챙겨주는 Agent**는 아닙니다. 예컨대 내일배움카드는 실업 상태라면 구직등록이 필요한 경우가 있고 훈련비 지원도 제공하지만, 사용자가 알아서 제도를 찾아 신청해야 합니다.

반면 **정책 자체**에는 취준생에게 굉장히 특화된 것들이 많습니다.

예를 들어 서울 청년수당은 2026년 기준 **서울 거주 만 19~34세의 최종학력 졸업 후 미취업자**를 대상으로 월 50만 원씩 최대 6개월 지원합니다.

중랑구에는 아예 **미취업 청년 자격증 응시료**를 최대 10만 원 지원하는 사업이 있습니다.

국민취업지원제도의 청년특례 역시 15~34세 청년을 대상으로 일정 조건에서 **월 60만 원 × 6개월의 구직촉진수당**과 취업지원서비스를 제공합니다.

즉,

> **취준생에게 특화된 정책은 많다.
그런데 그것들을 ‘취준생의 현재 취업 준비 상황’에 맞춰 능동적으로 연결해주는 서비스가 상대적으로 약하다.**
> 

여기에 기회가 있습니다.

# 제가 보기에는 방향을 이렇게 잡는 게 훨씬 좋습니다

## 취준생의 `지원금 검색 Agent`가 아니라

## **취업 준비 비용 절감 Agent**

사용자에게

> 당신은 받을 수 있는 정책이 17개입니다.
> 

라고 보여주는 게 아닙니다.

Agent가 사용자의 **취준 행동을 이해**하는 겁니다.

예를 들어 사용자가 말합니다.

> 다음 달에 토익 시험을 봐.
> 

그러면 Agent가:

> 현재 거주지역에 미취업 청년 어학시험 응시료 지원사업이 있는지 확인
> 
> 
> → 조건 확인
> 
> → 신청 가능한 경우 응시 후 필요한 증빙 안내
> 
> → 신청기간에 알림
> 

을 해줍니다.

---

사용자가:

> 다음 주에 성남에 있는 회사 면접이 있어.
> 

라고 하면:

```
면접 발생
↓
거주지역 확인
↓
현재 신청 가능한 면접수당 탐색
↓
교통비 지원 탐색
↓
면접 정장 무료대여 탐색
↓
관련 증빙서류 확인
↓
면접 후 신청 시점 알림
```

이렇게 움직이는 겁니다.

이건 일반 청년정책 추천과 상당히 다릅니다.

# 핵심 차이는 `Who you are`와 `What you're doing`입니다

현재 정책추천 서비스는 대부분 다음 정보에 의존합니다.

```
나이
성별
거주지역
소득
취업 여부
가구 형태
```

즉 **Who you are**입니다.

그런데 취준생 Agent는 여기에

```
다음 주 면접
토익 시험 신청
자격증 시험 예정
부트캠프 신청
대학 졸업
인턴 지원
퇴사 후 구직 시작
6개월째 미취업
다른 지역으로 면접 이동
포트폴리오 교육 수강
```

같은 **What you're doing**을 넣는 겁니다.

이 차이가 상당히 큽니다.

# 예를 들어 이런 UX가 훨씬 의미 있습니다

취준생 A:

```
24세
서울 중랑구
대학 졸업
현재 미취업
데이터분석 직무 준비
```

이번 달 일정:

```
9월 5일 TOEIC
9월 13일 SQLD
9월 18일 A기업 면접
9월 23일 B기업 면접
10월부터 Python 교육 수강 예정
```

Agent는 정책 DB와 이 일정을 조합합니다.

그리고 사용자에게:

> **이번 달 받을 수 있는 취준 혜택**
> 
> 
> **TOEIC + SQLD 응시료**
> 
> 중랑구 미취업청년 자격증 응시료 지원 대상일 가능성이 있습니다.
> 
> 최대 지원한도: 10만 원
> 
> → 시험 응시확인 자료를 보관하세요.
> 
> **9월 18일 면접**
> 
> 현재 적용 가능한 면접 관련 지원사업을 확인했습니다.
> 
> → 면접확인서가 필요한 경우 면접 직후 받아두세요.
> 
> **10월 Python 교육**
> 
> 국민내일배움카드 적용 가능 과정인지 확인할 수 있습니다.
> 
> 현재 실업 상태라 카드 신청 전 구직등록이 필요할 수 있습니다.
> 

이런 식입니다.

이때 중요한 숫자는

> **“취업 준비 가능기간 2.9개월”**
> 

이 아니라

> **“이번 달 예정된 취준 비용 31만 원 중 최대 14만 원을 지원받을 가능성이 있습니다.”**
> 

입니다.

이건 사용자에게 바로 가치가 있습니다.

# 그러면 금융 AI라는 것도 더 명확해집니다

서비스 핵심 질문을 이렇게 잡으면 됩니다.

> **“취업 준비 과정에서 내가 굳이 내 돈으로 지출하지 않아도 되는 비용은 무엇인가?”**
> 

취준생은 생각보다 돈을 많이 씁니다.

- 어학시험
- 자격증 시험
- 면접 교통비
- 면접 정장
- 증명사진
- 교육비
- 코딩/직무교육
- 포트폴리오 교육
- 면접 준비
- 주거비
- 생활비

그런데 중앙정부와 지방정부에 여러 지원제도가 분산돼 있습니다.

Agent가 이걸 **취준 일정과 연결**하면 됩니다.

# 이 아이디어의 진짜 Agent성

단순 추천은:

```
사용자 정보
↓
정책 검색
↓
추천
```

한 번 하고 끝입니다.

여러분 서비스는:

```
               취준생 프로필
                    │
                    ▼
             현재 지원가능 정책
                    │
                    ▼
          ┌── 취준 이벤트 감지 ──┐
          │                      │
      시험 신청                면접 예정
          │                      │
          ▼                      ▼
     응시료 지원 검색       면접 관련 지원 검색
          │                      │
          └────────┬─────────────┘
                   ▼
              자격조건 판단
                   │
                   ▼
              신청 시점 관리
                   │
                   ▼
              증빙자료 안내
                   │
                   ▼
             마감 전 재알림
                   │
                   ▼
              신청 완료 확인
                   │
                   ▼
              다음 이벤트 대기
```

이렇게 **지속적으로 취준생을 따라다녀야 Agent라고 부를 만합니다.**

# 더 재미있는 부분은 ‘정책을 놓치는 이유’를 해결할 수 있다는 겁니다

사람들이 반드시 정책 자체를 몰라서 놓치는 것은 아닙니다.

예를 들어

> “면접비 지원이 있다는 건 알고 있었는데 면접확인서를 안 받아놨다.”
> 

또는

> “시험 응시료 지원이 있었는데 영수증을 버렸다.”
> 

또는

> “지원대상이었는데 예산 소진으로 조기 마감됐다.”
> 

같은 문제가 있습니다.

실제로 현재 중랑구의 미취업청년 자격증 응시료 사업도 **예산 소진 시 조기 마감 가능**하다고 안내되어 있습니다.

이런 경우 Agent는 면접이나 시험 **이후가 아니라 이전**에 개입해야 합니다.

> 내일 면접이 있습니다.
> 
> 
> OO 지원사업 신청 시 면접 증빙이 필요할 수 있으므로 면접확인서를 받아두세요.
> 

이런 것이 실제적인 Agent 기능입니다.

|  | 청년몽땅정보통 | 고용24 | 일반 정책추천 | **여러분 Agent** |
| --- | --- | --- | --- | --- |
| 청년정책 검색 | O | O | O | O |
| 개인조건 기반 추천 | O | 일부 O | O | O |
| 취준생만을 대상으로 함 | X | X | X | **O** |
| 시험 일정 이해 | X | X | X | **O** |
| 면접 일정 이해 | X | X | X | **O** |
| 취준 행동 → 정책 연결 | X | X | 거의 X | **핵심** |
| 필요한 증빙 사전 안내 | 정책별 | 정책별 | 제한적 | **O** |
| 마감 지속 관리 | 제한적 | 제한적 | 일부 O | **O** |
| 취준비용 절감액 계산 | X | X | X | **O** |
| 취준 lifecycle 관리 | X | 일부 | X | **O** |

여기서 **`취준생만을 대상으로 한다`는 것 자체는 차별점이 아닙니다.**

진짜 차별점은

> **“취준생의 행동과 일정을 이해하고, 해당 행동 때문에 발생하는 비용을 줄여줄 정책을 필요한 순간에 먼저 찾아준다.”**
> 

입니다.

## 저는 오히려 이 버전이면 꽤 괜찮다고 봅니다

서비스를 한 문장으로 만들면:

> **취준생의 면접·시험·교육·구직 일정을 추적하여, 각 순간에 받을 수 있는 금융·정책 혜택을 찾아 신청과 증빙까지 관리해주는 AI Agent**
> 

조금 더 서비스스럽게 표현하면:

> **“취업 준비하면서 쓸 돈, 몰라서 내지 않게 해주는 AI.”**
> 

이 방향이면 **취준생 특화성 + 금융성 + Agent성** 세 가지가 동시에 생깁니다.
