# FINANCE 테이블 — 정책 판정용 금융 피처 정의

> 목적: **정책 자격 판정에 직접 등장하는 금융정보만** 담는 가공 테이블.
> RAW(MYDATA_*)와 설문(PROFILE_SURVEY)에서 계산·복사해 채우며, **LLM 매칭 엔진의 입력**이 된다
> (매칭 시 거래내역 수십 행 대신 이 테이블 한 행만 전달 → 프롬프트 간결, 판정 근거 명확).

## 선별 방법

행정안전부 대한민국 공공서비스(혜택) API에서 취준생 관련 키워드 20종으로 정책을 수집,
중복 제거 후 **취준 관련 178건**의 `지원대상`·`선정기준` 원문에서 금융 요건 패턴을 채굴했다 (2026-09-03).

| 요건 패턴 | 건수 | 비율 |

| 거주 기간 | 60 | 34% |
| 졸업·재학 | 31 | 17% |
| **중위소득 기준** | 21 | 12% |
| 소득 절대액·구간 | 12 | 7% |
| 기초수급·차상위 | 8 | 4% |
| 고용보험 | 8 | 4% |
| 무주택 | 7 | 4% |
| 대출·부채 | 5 | 3% |
| 건강보험료 판정 | 4 | 2% |
| 보증금·월세 상한 | 3 | 2% |
| 취업경험 | 3 | 2% |
| 재산 가액 | 1+ | 1% |

- 상위 4개(나이·미취업·거주·졸업)는 비금융 → PROFILE_SURVEY 담당
- 조사에서 **새로 발견되어 추가된 피처**: ⑭ 기초수급·차상위 여부, ⑮ 원가구(부모) 합산 연소득
  - 근거: 세종시 임차보증금 이자지원 "취업준비생: 본인 연소득 4,500만 이하 + **부모 합산 연소득 7,000만 이하**",
    청년주택 이자지원 "(취업준비생 등 무소득자) **부모 연소득 1억 이하**" — 무소득 취준생은 부모 소득을 절대액으로 판정

## FINANCE 테이블 피처 15개

| # | 컬럼 | 타입 | 출처 | 근거 정책 예 |
|---|---|---|---|---|
| | ID (PK, FK) | text | — | |
| | 기준일 | date | — | 계산 시점 |
| **소득** |||||
| 1 | 월평균근로소득 | int | 🔄 MYDATA_TRANSACTION | 국취제 수당 감액, 청년내일저축(월 50~230만), 청년수당 단기근로 |
| 2 | 소득관측개월수 | int | 🔄 도출 | 신뢰도 표시 |
| 3 | 연환산소득 | int | 🔄 도출 (1×12) | 햇살론유스(3,500만↓), 청년도약계좌, 세종 이자지원(본인 4,500만↓) |
| 4 | 가구중위소득구간 | text | 📝 SURVEY 복사 | 국취제 60%, 청년수당 150%, 월세지원, 주거비지원 180% |
| 5 | 원가구부모연소득구간 | text | 📝 설문 추가 | 임차보증금 이자지원 계열 (7,000만·1억 등 절대액) |
| 6 | 건보자격 | text | 📝 SURVEY | 직장·지역·피부양 — 소득 판정 방식 결정 |
| 7 | 월건보료 | int | 📝 설문 (지역가입 자동이체는 🔄 도출 가능) | 지자체 다수가 건보료 고지액으로 소득 판정 |
| 8 | 수급중제도 (명·월액·시작월·종료추정월) | jsonb | 🔄 도출 (수당 입금 감지) | 중복수급 배제, 종료 시점 lifecycle |
| **재산** |||||
| 9 | 금융재산총액 | bigint | 🔄 ACCOUNT+INVESTMENT 합산 | 청년월세 본인 금융재산 한도, 전세임대 총자산 |
| 10 | 가구재산구간 | text | 📝 SURVEY 복사 | 국취제 재산 4억(청년 5억) |
| 11 | 무주택여부 | boolean | 📝 SURVEY | 청년월세, 주거비지원, 청약 |
| 12 | 임차보증금·월세액 | int·int | 보증금 📝 / 월세 🔄 도출 | 주거비지원(보증금 3천만+월세 50만↓), 월세자금보증(1억+60만↓) |
| **부채** |||||
| 13 | 대출잔액 (유형별: 학자금·신용·전세) | jsonb | 🔄 MYDATA_LOAN | 햇살론유스, 학자금 상환유예·이자지원 |
| 14 | 연체·상환애로여부 | boolean | 🔄 MYDATA_LOAN 상환상태 | 신용회복·서민금융 연계 |
| **자격·이력** |||||
| 15 | 기초수급·차상위여부 | text | 📝 설문 추가 | 응시료 면제, 훈련 우대, 취업성공수당 등 8건 |
| 16 | 고용보험가입개월·최근이직일 | int·date | 📝 SURVEY (급여 입금 🔄 추정 보조) | 구직급여 180일, 국취제 취업경험, 청년수당 제외요건 |
| 17 | 미취업지속개월 | int | 🔄 도출(급여 부재) + 📝 보정 | 장기 미취업 우대 |

🔄 = MYDATA RAW에서 계산 / 📝 = PROFILE_SURVEY에서 복사(설문)

- 값이 없으면 `NULL`("모름") — 매칭 엔진은 추측 대신 **"추가 확인 필요 + 확인 방법"** 안내
- FINANCE는 재계산 가능한 **파생 테이블(피처 스토어)** — 원천은 항상 MYDATA_* / PROFILE_SURVEY
- PROFILE_SURVEY에 설문 항목 2개 추가 필요: **기초수급·차상위 여부**, **원가구(부모) 합산 연소득 구간**

## 조사 한계

- 서비스명·지원대상 키워드 검색 기반이라 완전 전수는 아님. 온통청년(청년정책) Open API 키 발급 시 청년정책 전수로 보강 예정
- 다만 178건에서 요건 **유형**은 수렴 — 새 유형의 금융 요건이 더 나타나지 않음
